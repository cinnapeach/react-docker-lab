# React App в Docker (Лабораторная работа №3)

**Краткое описание:** 
Простое React-приложение (интерактивный счетчик кликов), собранное с использованием многоступенчатого `Dockerfile` и раздаваемое через веб-сервер Nginx. Проект демонстрирует навыки контейнеризации frontend-приложений.

(находися в браузере по адресу http://localhost:8080)*

## Инструкция по сборке Docker-образа

Для сборки образа выполните следующую команду в корневой директории проекта (где находится Dockerfile):

```bash
docker build -t react-app:latest .
